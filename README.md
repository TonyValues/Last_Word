# המילה האחרונה

משחק דפדפן פשוט: המילה הראשונה מוצגת, וכל טעות חושפת מילה נוספת. המטרה היא לנחש את המילה האחרונה בכמה שפחות טעויות.

## הפעלה מקומית
פתחו את `index.html` בדפדפן.

## הוספת משחקים
ערכו את `games.js` והוסיפו אובייקטים בפורמט:

```js
{ id: 11, words: ["רמז 1", "רמז 2", "רמז 3"], answer: "התשובה" }
```

## פרסום באינטרנט
1. צרו repository חדש ב-GitHub.
2. העלו אליו את שלושת קבצי המשחק (`index.html`, `style.css`, `games.js`, וגם `README.md` אם רוצים).
3. ב-GitHub: Settings → Pages → Deploy from a branch → `main` → `/root`.
4. שמרו והמתינו לפרסום.
5. תקבלו כתובת ציבורית בסגנון `https://USERNAME.github.io/REPOSITORY/`.

אין צורך בשרת עבור הגרסה הזאת.
