# המילה האחרונה

משחק דפדפן יומי: המילה הראשונה מוצגת, וכל ניחוש שגוי חושף מילה נוספת. המטרה היא לנחש את המילה האחרונה בכמה שפחות ניחושים.

המשחק כולל ארכיון משחקים, סטטיסטיקה אישית שנשמרת בדפדפן, תוצאה לשיתוף ותצוגה מותאמת לנייד. במשחק האחרון שפורסם אפשר להמשיך לנחש גם אחרי שכל הרמזים נחשפו, אך התשובה לא תוצג. תשובה מוצגת בניצחון, או לאחר ויתור על משחק ישן יותר.

## הפעלה מקומית
העלו את התיקייה לשרת סטטי, למשל באמצעות Live Server ב-VS Code, ופתחו את `index.html` דרך הכתובת שהשרת מספק. טעינת `games.csv` דורשת HTTP ולא פתיחה ישירה של קובץ `file://`.

## הוספת משחקים
ערכו את `games.csv` והוסיפו שורה אחת לכל משחק. העמודות הן:

`id,date,author,words,answers,explanation`

הפרידו בין רמזים ובין תשובות חלופיות באמצעות `|`:

```csv
11,21/08/2026,"שם היוצר","רמז 1|רמז 2|רמז 3","התשובה|תשובה חלופית","הסבר קצר על הקשר בין הרמזים לתשובה."
```

אם ההסבר כולל פסיקים, השאירו את השדה בתוך מרכאות כפולות.

הצעות המשחק נשלחות לכתובת `yuvalst3@gmail.com` באמצעות FormSubmit. בפעם הראשונה, FormSubmit עשוי לשלוח אליך הודעת אישור; יש לאשר אותה כדי להפעיל את קבלת ההצעות. לאחר האישור, הטופס שולח את הנתונים ישירות לכתובת שלך ללא צורך בתוכנת אימייל אצל המבקר.

## פרסום באינטרנט
1. צרו repository חדש ב-GitHub.
2. העלו אליו את קבצי האתר: `index.html`, `style.css`, `games.csv`, `app.js` וגם `README.md` אם רוצים.
3. ב-GitHub: Settings → Pages → Deploy from a branch → `main` → `/root`.
4. שמרו והמתינו לפרסום.
5. תקבלו כתובת ציבורית בסגנון `https://USERNAME.github.io/REPOSITORY/`.

אין צורך בשרת עבור הגרסה הזאת. סטטיסטיקת השחקן נשמרת מקומית בדפדפן ואינה נשלחת לשרת.
